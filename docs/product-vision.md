# Product Vision

## PMPLtool

**Product Manager Problem Learning Tool**

PMPLtool is a guided product problem-solving and learning tool for aspiring and practicing Product Managers.

The user starts with a product problem, signal, question, or assumption.

PMPLtool then helps the user understand what to investigate and what to do next.

The core principle is:

> The problem determines the roadmap.

Instead of forcing every product problem through the same process, PMPLtool should identify which Product Management activities are relevant to the specific problem.

For example, depending on the problem, the tool may recommend:

- User research
- User interviews
- App review analysis
- Product analytics
- Funnel analysis
- Metrics investigation
- Root-cause analysis
- Competitor analysis
- Market research
- Hypothesis formation
- Prioritization
- Experimentation
- Prototyping
- Usability testing
- Solution exploration
- PRD creation
- User stories
- Acceptance criteria
- Engineering feasibility
- Launch planning
- Success metrics
- Post-launch measurement
- Iteration

The tool should not assume that the user's initial understanding is correct.

User inputs should be treated as facts, signals, assumptions, or hypotheses depending on the evidence provided.

PMPLtool should help the user identify:

- What is known
- What is unknown
- What is assumed
- What evidence supports an assumption
- What evidence contradicts it
- What information is missing
- What should be investigated next

Where reliable external product or market data is available, PMPLtool may eventually use it to validate or challenge assumptions.

The long-term goal is to guide a Product Manager through a complete problem-solving journey:

Problem
→ Investigation
→ Evidence
→ Root Causes
→ Hypotheses
→ Prioritization
→ Solution Direction
→ Prototype
→ Validation
→ PRD
→ Build
→ Launch
→ Measure
→ Learn
→ Product Roadmap

PMPLtool is not intended to replace Product Managers.

It is intended to help them think more systematically, learn Product Management concepts through practice, and make better-informed decisions.
